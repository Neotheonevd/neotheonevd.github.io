Selected research 论文与研究

JESDReID
ICLR 2027 SUBMISSIONUnder review / 在审

Aligning without Homogenizing: Jointly Explainable Common-Specific Decomposition for Multi-Modal Object Re-Identification

Co-first author, listed first · 共同第一作者，排名第一

Align multimodal representations while preserving complementary evidence.
在对齐多模态表征的同时，保留有用的互补信息。

Research overview 研究概述+

JESD-ReID separates shared and modality-specific evidence using a joint-explainability criterion. It coordinates common information and modality-specific residuals with different constraints, then adaptively aggregates complementary evidence for object re-identification.

JESD-ReID 以共同可解释性区分共性与模态特有信息，对两类信息施加差异化约束，并通过自适应融合保留互补线索，用于多模态目标重识别。
